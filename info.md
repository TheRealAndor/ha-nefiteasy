Control your Nefit Easy thermostat from Home Assistant, with a connection to the Bosch cloud that recovers by itself.

- Self-healing connection and a 20 s request timeout for the slow Bosch cloud
- `Bosch cloud connection` sensor with the time and reason of outages
- Diagnostics download with all secrets removed
- Same `nefiteasy` domain as ksya/ha-nefiteasy: configuration and entities stay

See the [README](https://github.com/TheRealAndor/ha-nefiteasy) for setup, entities and examples.
